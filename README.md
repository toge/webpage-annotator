# Webpage Annotator

YAML 形式で指定した CSS セレクタに一致する DOM 要素へ、枠線と連番バッジをオーバーレイ描画する Google Chrome 拡張機能（Manifest V3）です。

## 主な機能

- **サイドパネルでの YAML 編集**: Chrome のサイドパネルから CSS セレクタ・色・余白を YAML 形式で指定し、アクティブなタブへ即座に反映できます。
- **設定の自動保存**: 入力した YAML 設定は `chrome.storage.local` に自動保存され、次回サイドパネルを開いた際に復元されます。
- **ショートカットキー対応**: エディタ内で `Ctrl+Enter`（macOS は `Cmd+Enter`）を押して描画を適用できます。
- **スクロール・リサイズ追従**: ウィンドウのリサイズやスクロール（ネストされたスクロールコンテナを含む）に合わせてオーバーレイ位置をリアルタイムに追従します。
- **重複・非表示要素の自動除外**:
  - 複数のルールに重複して一致する要素は、先頭に記述されたルールを優先して 1 回のみ描画します。
  - `display: none` の要素や、描画サイズが 0（幅または高さが 0 以下）の要素は自動的にスキップします。
- **バッジ位置の自動調整**: 連番バッジは通常、枠線の左上外側に表示されます。要素が画面上端に近く外側へはみ出す場合は、自動的に枠線の左上内側へ配置を切り替えます。
- **非破壊オーバーレイ**: オーバーレイには `pointer-events: none` を設定しているため、ページ本来のレイアウトやクリック操作を妨げません。
- **ライト / ダークモード対応**: サイドパネル UI はブラウザ・OS の配色設定（`prefers-color-scheme`）に自動で追従します。

## 動作要件

- Google Chrome 114 以降（Manifest V3 および Side Panel API 対応ブラウザ）

## インストール方法

1. このリポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/toge/webpage-annotator.git
   ```
2. Google Chrome のアドレスバーに `chrome://extensions` と入力して拡張機能ページを開きます。
3. 右上の **「デベロッパー モード」** をオンにします。
4. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックし、本リポジトリのルートディレクトリ（`manifest.json` が含まれるフォルダ）を選択します。

## 使い方

1. ツールバーの **Webpage Annotator** アイコンをクリックしてサイドパネルを開きます。
2. **「YAML設定」** エディタにルールを記述します（初回起動時はサンプル設定が入力されています）。
3. **「描画適用」** ボタンをクリックするか、エディタ内で `Ctrl+Enter`（macOS は `Cmd+Enter`）を押すと、アクティブなタブの該当要素に枠線と連番バッジ（デフォルトは `1` から全体通番、`startNumber` で開始番号、`numberingMode` で全体採番／ルールごと採番、各ルールの `prefix`・`suffix` で接頭辞・接尾辞を指定可能）が描画されます。
4. オーバーレイを消去したい場合は **「クリア」** ボタンをクリックします。

## YAML 設定仕様

ルートに `rules` 配列（および任意の `startNumber`、`numberingMode`）を持つオブジェクト形式で記述します。

### 設定例

```yaml
startNumber: 10 # 省略時は 1 から採番
numberingMode: "perRule" # "global"（省略時: 全体で採番）または "perRule"（ルールごとに採番）
rules:
  - selector: "a"
    color: "#FF3B30"
    padding: 2
    prefix: "L-"
  - selector: "button, input[type='submit']"
    color: "#007AFF"
    padding: 4
    prefix: "BTN "
    suffix: "件"
```

### ルート項目

| キー | 必須 | 型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| `startNumber` | 任意 | 整数 | `1` | 連番バッジの開始番号（`0` 以上の安全な整数） |
| `numberingMode` | 任意 | 文字列 | `"global"` | 採番方式（`"global"`: 全体で採番、`"perRule"`: ルールごとに `startNumber` から採番） |
| `rules` | 必須 | 配列 | なし | 描画ルールの配列 |

### ルール項目

| キー | 必須 | 型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| `selector` | 必須 | 文字列 | なし | 描画対象を指定する CSS セレクタ |
| `color` | 任意 | 文字列 | `"#FF3B30"` | 枠線とバッジ背景の色（HEX、RGB、色名など有効な CSS カラー） |
| `padding` | 任意 | 数値 | `0` | 対象要素の外側へ広げる余白（単位: px、0 以上の数値） |
| `prefix` | 任意 | 文字列 | `""` | 連番の前に付与する接頭辞（前後空白を保持） |
| `suffix` | 任意 | 文字列 | `""` | 連番の後ろに付与する接尾辞（前後空白を保持） |

### バリデーションとエラー時の挙動

- YAML の構文エラー、`rules` が配列でない場合、`startNumber` に `0` 以上の整数以外（負数・小数・文字列・真偽値など）が指定された場合、`numberingMode` に `"global"`・`"perRule"` 以外が指定された場合、またはルールの `prefix`・`suffix` に文字列以外が指定された場合はエラーを表示して処理を中断します。
- 個別ルール内の不正な CSS セレクタやオブジェクトでないエントリは警告を表示してスキップし、残りの有効なルールを適用します。
- 不正な `color` や負数・数値以外の `padding` が指定された場合は、警告を表示したうえでデフォルト値（`#FF3B30` / `0`）を使用します。

## 動作確認用ページ

リポジトリ内の [`test.html`](test.html) を使って、以下の動作を確認できます。

- 画面上端付近の要素におけるバッジの内側配置切り替え
- 複数ルールに重複マッチする要素の 1 回描画
- `display: none`・親要素が非表示・幅 0・高さ 0 要素のスキップ
- ウィンドウリサイズ時の右寄せ要素への追従

> **Note:** `test.html` を `file://` URL で直接開いて確認する場合は、`chrome://extensions` から Webpage Annotator の **「詳細」** を開き、**「ファイルの URL へのアクセスを許可する」** を有効にしてください。

## 使用している権限

| 権限 | 用途 |
| --- | --- |
| `sidePanel` | サイドパネル UI の表示およびツールバーアイコンクリックでの開閉 |
| `activeTab` | 現在アクティブなタブの取得 |
| `scripting` | 対象タブへのオーバーレイ描画スクリプト（`content.js`）の動的注入 |
| `storage` | YAML 設定のローカル保存・復元（`chrome.storage.local`） |
| `<all_urls>` | 任意の Web ページ上へのオーバーレイ描画 |

## 制限事項

- `chrome://` ページや Chrome ウェブストアなど、Chrome のセキュリティ仕様によりスクリプト注入が禁止されているページでは動作しません。

## ファイル構成

```text
.
├── manifest.json       # Chrome 拡張機能マニフェスト（Manifest V3）
├── background.js       # アイコンクリックでサイドパネルを開く Service Worker
├── sidepanel.html      # サイドパネル UI の HTML / CSS
├── sidepanel.js        # YAML パース・バリデーション・設定保存・タブ通信
├── content.js          # オーバーレイ（枠線・連番バッジ）描画・位置追従・クリア処理
├── lib/
│   └── js-yaml.min.js  # YAML パーサライブラリ（js-yaml）
└── test.html           # 動作確認用サンプルページ
```
