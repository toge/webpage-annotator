# ルールごとの固定テキスト指定機能（`text`）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** YAML の各ルール項目に任意の `text`（文字列）を追加し、1 文字以上の文字列が指定された場合は採番を行わず `text` の値をそのまま表示ラベルとし、`numberingMode: "global"` の全体採番カウンタも増やさないようにする。

**Architecture:** `sidepanel.js` の `parseAndValidateYaml` で各ルールの `text`（未指定・`null`・`""` は `null`、1 文字以上の文字列は前後空白を保持、文字列以外はルール番号付きエラー送出）を検証・正規化して `rules` に含める。`content.js` の `applyAnnotations` でも同じ規則で防御的バリデーションを行い、独立した全体採番カウンタ `globalNumberedCount` を導入して、`text !== null` の要素は採番カウンタを進めず `label: text`・`index: null` として描画する。

**Tech Stack:** Chrome Extension (Manifest V3), Vanilla JavaScript, js-yaml, GJS (`gjs`) による自動テスト

## Global Constraints

- `text` のデフォルト値は `null`（未指定扱い）。
- 未指定（`undefined`）、`null`（`text:`）、空文字列（`""`）はいずれも `null` に正規化し、通常どおり採番（`${prefix}${index}${suffix}`）を行う。
- 1 文字以上の文字列（`typeof value === "string" && value.length > 0`）は `trim()` せずそのまま表示ラベルとし、`prefix` / `suffix` は適用しない。
- 文字列以外の型（数値、真偽値、配列、オブジェクト等）が指定された場合はフォールバックせず、以下のエラーで処理を中断する。
  - `` `ルール #${ruleNo}: 'text' は文字列で指定してください。` ``（`content.js` は `ruleIndex + 1`）
- `text` が有効なルールに一致した要素では、全体採番カウンタ（`globalNumberedCount`）およびルール内採番カウンタ（`ruleMatchedCount`）を増やさず、`Number.isSafeInteger` の上限チェックも行わない。
- 表示ラベルは `badgeEl.textContent`、`data-webpage-annotator-box`、`data-webpage-annotator-badge` のすべてに一致して設定する。
- 重複除外（`seenElements`）、オーバーレイ除外（`isOverlayNode`）、非表示除外（`isElementVisible`）、総描画件数（`res.count`）は `text` ルールも従来どおり対象とする。
